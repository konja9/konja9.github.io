プライバシーポリシー

対象：パチふと（Android アプリ・Web 版）　制定日：2026年10月2日

konja9（以下「運営者」）は、麻雀の点数計算トレーニングアプリ「パチふと：麻雀の点数計算をパチンコで練習」（以下「本アプリ」）における利用者の情報の取り扱いを、以下のとおり定めます。

1. 運営者が集める情報

運営者は、利用者の氏名・メールアドレス・位置情報などの個人情報を、運営者のサーバーに集めません。本アプリには、利用者が登録するアカウントもありません。

成績・所持金（ゲーム内の通貨）・設定などのゲームのデータは、利用者の端末の中だけに保存されます。運営者に送られることはありません。本アプリを削除すると、これらのデータも消えます。

2. 広告（Android アプリのみ）

本アプリの Android 版は、Google LLC の広告配信サービス「Google AdMob」を使って広告を表示します。AdMob は、広告の配信・効果測定・不正防止のために、次の情報を収集・利用することがあります。

  • 広告 ID（Android の広告 ID）
  • IP アドレスと、そこから推定されるおおよその位置
  • 端末の種類・OS のバージョン・言語などの端末情報
  • 広告の表示・タップなどの操作の記録

これらの情報は Google のプライバシーポリシーに従って取り扱われます。詳しくは Google のサービスを使用するサイトやアプリから収集した情報の Google による使用 と Google の広告に関するポリシー をご覧ください。

欧州経済領域（EEA）・英国・スイスなどの利用者には、初回の起動時に、広告のためのデータ利用について同意を確認します。同意の内容は、アプリの「設定 › 広告 › プライバシー設定」からいつでも変更できます。

広告のカスタマイズは、Android の「設定 › プライバシー › 広告」（端末により「Google › 広告」）から、広告 ID のリセット・削除によって止めることができます。

3. 広告削除の購入（Android アプリのみ）

広告削除の購入は、Google Play の決済の仕組みで行われます。お支払いに使うカード番号などの情報は Google が取り扱い、運営者には届きません。

本アプリは、広告を消すかどうかを判断するために、Google Play から購入の有無（商品 ID と購入の状態）だけを受け取ります。この情報は端末の中で使うだけで、運営者のサーバーには送りません。

4. Web 版

Web 版（https://konja9.github.io/mahjong-app/）には、広告・アクセス解析・購入の機能はありません。Web 版は GitHub, Inc. の GitHub Pages で配信しており、GitHub がサービスの運用のためにアクセスの記録（IP アドレスなど）を取ることがあります。詳しくは GitHub のプライバシーに関する声明 をご覧ください。

5. 第三者への提供

運営者は、上の 2〜4 に書いたサービスの提供元を除き、利用者の情報を第三者に提供しません。運営者自身が利用者の個人情報を持たないため、運営者から提供することもありません。

6. 子どもの利用

本アプリは 13 歳未満の子どもを対象としていません。13 歳未満の子どもの情報を、意図して集めることはありません。

7. このポリシーの変更

運営者は、必要に応じてこのポリシーを変更することがあります。大きな変更は、このページで制定日・改定日とあわせてお知らせします。
